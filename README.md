# C# Decision Making

A beginner-friendly C# Console Application demonstrating all major **Decision Making Statements** with simple examples and explanations.

## 📌 Topics Covered

- ✅ If Statement
- ✅ If-Else Statement
- ✅ Else If Statement
- ✅ Nested If Statement
- ✅ Switch Statement
- ✅ Conditional (Ternary) Operator

## 📂 Project Structure

```
DecisionMaking
│
├── Program.cs
├── IfStatement.cs
├── IfElseStatement.cs
├── ElseIfStatement.cs
├── NestedIfStatement.cs
├── SwitchStatement.cs
└── ConditionalOperator.cs
```

## 🚀 Features

- Simple and beginner-friendly examples
- Clean and well-commented code
- Separate class for each concept
- Easy to understand and modify
- Ideal for C# beginners and .NET learners

## 🛠 Technologies Used

- C#
- .NET
- Visual Studio 2026

## ▶️ How to Run

1. Clone the repository

```
git clone https://github.com/pandi-vigneshwari/csharp-DecisionMaking.git
```

2. Open the project in Visual Studio.

3. Build and Run the project.

## 🎯 Learning Objectives

After completing this project, you will understand:

- Different types of if statements

- Conditional (Ternary) Operator
- Writing clean and readable decision logic
